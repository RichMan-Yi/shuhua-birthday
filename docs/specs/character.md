程式：[src/wolf.js](../../src/wolf.js)、[viewer.html](../../viewer.html)、[src/viewer.js](../../src/viewer.js)

## 模型

全部用程式產生（沒有外部 3D 檔案），所有數值集中在 `WOLF_PARAMS`，同時供遊戲和調整面板使用。

| 部位 | 做法 |
|---|---|
| 頭 | 依 3d1 描出正面輪廓（頂部圓弧、兩頰最寬、下巴較平），再鼓成前後都有深度的布偶狀。前面厚 0.48、後腦 0.52（約和頭高一樣深） |
| 耳朵 | 獨立的圓角三角形，從頭頂後方長出來；內側是白色；預設朝外轉 12°、往後傾 4° |
| 五官 | 依 3d1 的像素位置投影到臉上：深藍眼睛（白色大反光＋淺藍小反光、外眼角睫毛）、凸出的粉紅鼻子、ω 嘴加一顆虎牙、粉紅腮紅（左臉兩個小點）、額頭淺灰「ω」紋路 |
| 身體 | 略呈西洋梨形的旋轉體，寬約頭寬的 38%；胸前白色愛心貼合身體曲面 |
| 手腳 | 短短的灰色手臂、白色手掌；短腿、白色腳掌 |
| 尾巴 | 從屁股後方往外、往上彎的曲線，白色尾巴尖 |
| 描邊 | 3D 參考圖沒有黑色描邊，所以預設關閉；調整面板可以打開 |
| 顏色 | 毛色 #CDCDD2、白色部位 #F4F4F6、額頭紋路 #A9A9AF、眼睛 #124A86、腮紅 #F7A3C2、鼻子 #F27E9B |

尺寸：含耳朵約 1.6 單位高，面向 +z，腳踩在 y = 0。

動作（由各場景驅動）：待機搖頭、搖尾巴、走路擺手、揮手、雙手抱籃子、划船、被撞時抖動。

## 模型檢視頁（viewer.html）

**檢視分頁**
- 參考圖列：點任一張，會在角落以子母畫面顯示，鏡頭同時轉到相近的角度。
- 正面疊圖比對：用無透視的正面鏡頭，把 3d1 和模型以同一比例疊在一起，可調透明度。
- 視角：正面、斜側、側面、另一側、背面、俯視；可以自由拖曳、縮放、平移。
- 動作：待機、走路、揮手、抱籃子；可以暫停、自動旋轉。
- 顯示：黑色描邊、線框；背景有天空、米白、草地、夜晚。
- 截圖、顯示三角形數量。
- 網址捷徑：`#compare`、`#front`、`#three`、`#side`、`#back`、`#top`、`#tune`。

**調整分頁**
- 52 個參數，分為頭型、耳朵、五官、身體、顏色五組；拉動即時重建模型。
- 有改過的項目標成紅色，每組顯示改了幾項；點兩下項目名稱恢復預設。
- 「按住看原版」、「復原」、「全部重設」（要按兩次）。
- 調整結果自動存在瀏覽器。
- 「複製設定給 Claude」：複製一段只包含改過項目的文字，貼給 Claude 後寫成新的預設值。

## 已知問題與待辦

- 耳朵是厚度均勻的板子，從斜側面看得出硬邊；參考圖的耳朵有厚度、邊緣圓潤、略微內凹。建議下一步重做。
- 背面和斜側的頭型還有些微差異。
- 參考圖若不是自己畫的，需要取得原作者同意，並在遊戲中標註作者。
