# 計分

## 需求

| 編號 | 需求 | 來源 |
|---|---|---|
| S1 | 之後要做分數排行榜 | 2026-10-24 |
| S2 | 每個關卡即使過關，都還是要有一個分數 | 2026-10-24 |
| S3 | 玩家結算時會得到一個總分 | 2026-10-24 |
| S4 | **分數要能細微區分**，例如快了 0.5 秒分數也會高一點 | 2026-10-24 |

## 原則

- 每關有兩個獨立的數字：
  - **印章進度**：決定能不能過關，例如「收成 30 點」。
  - **分數**：給排行榜用的細分分數。
- 分數 = 底分 + **連續變化的加成**（反應時間、剩餘時間、準度、剩餘耐心等）＋連續表現的倍率 − 失誤扣分。連續變化的項目讓分數幾乎不會同分，表現稍微好一點就會多一點分。
- 結算卡會列出每個項目的合計，玩家知道分數從哪裡來。
- 分數最低為 0，四捨五入成整數。

## 總分

- 每關的成績是**過關那一次的分數**；沒過關的嘗試不記錄（見 [progression.md](progression.md)）。
- 總分 = 五關成績加總，這也是祝福牆排名用的數字。

## 各關計分

詳細數值在各關的規格裡：[大溪](levels/daxi.md)、[拉拉山](levels/lalashan.md)、[石門](levels/shimen.md)、[Xpark](levels/xpark.md)、[夜市](levels/night.md)。

| 關卡 | 連續加成項目 |
|---|---|
| 大溪 | 每回合剩下的輸入時間 |
| 拉拉山 | 接在籃子中間的程度 |
| 石門 | 魚的跳躍高度、擦身閃過的距離、划行距離 |
| Xpark | 看到題目後的反應時間 |
| 夜市 | 客人剩下的耐心 |
