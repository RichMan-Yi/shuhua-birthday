# 石門水庫・划船大冒險

程式：[src/games/shimen.js](../../../src/games/shimen.js)

## 玩法

小狼坐在小船上往前划，左右拖曳控制方向，接住跳出水面的魚，閃開石頭和漂流木。

## 規則

- 時間 **40 秒**；船身有 3 格。**撞 3 次船就壞了，直接判定失敗**（即使魚已經夠了也一樣），結算顯示「船撞壞了！」。撞到後 1.2 秒內無敵（船會閃爍）。
- **船越划越快**（2026-10-24 加強）：速度從 8 加到 20，前段慢慢加、最後 10 秒加最多（8 + 12 × 進度^1.5）。每 10 秒跳出「加速！」並有提示音；鏡頭視角隨速度稍微變寬，小狼划槳的節奏也跟著變快。
- 物件：金色的魚 8%、魚 44%、石頭 30%、漂流木 18%；每 0.75 秒到 0.45 秒出現一次，有 25–50% 機率一次兩個（第一版的量）。40 秒內大約會出現 45 條魚（金色算 3 條）。
- 魚會一直跳出水面。
- **一定留出閃避的路**（2026-10-24）：放障礙物前，會連同前後 4 單位內已經有的障礙物一起檢查，船的可移動範圍（−W 到 W）裡至少要留一段 0.35 以上的空隙讓船通過；找 12 次都找不到這樣的位置，就改成一條魚。原本障礙物可以隨便放，直式手機的河道很窄（W 約 1.7），一根漂流木加一顆石頭就能把整條河擋住，貼到最邊也躲不掉。模擬 20 萬幀（約 110 分鐘）：原本有 448 幀整條河被擋住、一定會撞到；現在 0 幀。
- **印章門檻**：35 條魚（金色的魚算 3 條），而且船沒有撞壞。

## 計分

下表是**原始分數**；遊戲中顯示的分數會再換算，剛好過關約 1,000 分（見 [scoring.md](../scoring.md) 的「標準化」）。

| 項目 | 分數 |
|---|---|
| 魚 | +100 |
| 金色的魚 | +300 |
| 跳躍時機 | 一般最多 +80、金色最多 +150，依接到時魚跳的高度（連續值） |
| 擦身而過 | 障礙物在 0.6 單位內閃過時，最多 +90，越近越多（連續值） |
| 划行距離 | 每前進 1 單位 +2.5（持續累積） |
| 剩餘船身 | 結束時每格 +250 |
| 撞到障礙 | −150 |

## 畫面

- 湖面、白色水紋、兩側長滿樹的湖岸、遠方的山。
- 船：低船舷的木頭划艇（紅色吃水線、木板接縫、白色船緣、深色船艙、座板、船頭小旗），原本放大 1.25 倍，2026-10-24 再縮小到 90%（實際約 1.125 倍）；船和小狼一起縮小，撞到障礙、擦身而過、接魚的判定寬度也跟著縮小到 90%（0.55 → 0.495），判定和看到的船一樣大。小狼坐在座板上面向鏡頭，船緣在腰部，頭、身體、雙手都露在外面。
- 兩側各一支船槳裝在槳架上，跟著小狼的雙手一起前後划動，槳葉伸到水面。
