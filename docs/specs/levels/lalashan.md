# 拉拉山・接水蜜桃

程式：[src/games/peach.js](../../../src/games/peach.js)、水蜜桃模型在 [src/models.js](../../../src/models.js)

## 玩法

左右拖曳小狼，用手上的籃子接住從水蜜桃樹上掉下來的水蜜桃，避開蜜蜂。

## 規則

- 時間 **30 秒**。
- 掉落物：金色水蜜桃 9%；蜜蜂從 12% 隨時間增加到 24%；其餘是一般水蜜桃。
- 掉落間隔從 0.8 秒縮短到 0.45 秒；落地時間從 2.3 秒縮短到 1.4 秒（越後面越快）。金色的快 50%（2026-10-24 從 15% 調快）。
- 蜜蜂會左右飄；碰到蜜蜂，小狼會暈 0.6 秒不能移動。
- **印章門檻**：收成 30 點（一般 1、金色 3、蜜蜂 −2，最低 0）。

## 計分

| 項目 | 分數 |
|---|---|
| 水蜜桃 | +100 |
| 金色水蜜桃 | +300 |
| 接得準 | 一般最多 +60、金色最多 +120，依接到的位置離籃子中心多近（連續值） |
| 連續接到 | 底分 × min(60%, 5% × (連續數 − 1))；漏接或碰到蜜蜂就歸零 |
| 碰到蜜蜂 | −200 |

## 水蜜桃的造型

- 所有水蜜桃都是水蜜桃的形狀：頂端微尖、中間一道凹線（凹線顏色較深）、兩片葉子和果梗。
- 一般水蜜桃：奶油色漸層到粉紅色。
- 金色水蜜桃：同樣的形狀，淡金漸層到金色，保留一點粉橘色腮紅；有亮面反光、金色光暈、三顆環繞的閃光。

## 畫面

- 拉拉山果園：兩排水蜜桃樹、遠方的山、雲、土路。
- 直式手機的鏡頭會拉遠，並同比例放大小狼和掉落物，讓可移動範圍夠寬。
- 小狼雙手往前伸，抱著一個寬而淺的橢圓形籃子，籃子貼在肚子前面、手的高度，兩端各有一個提把讓手握著，下面看得到小狼的腳。籃子後緣在身體正面前方（身體最前面約 z 0.22，籃子後緣約 z 0.23），所以從正面看不會穿模（2026-10-24 修正兩次：原本的圓籃子太大，籃緣在腰部、下半身都在籃子裡，看起來像坐在籃子裡；縮小之後身體又穿過籃子後緣，所以改成橢圓形）。接住的判定範圍不變（左右 0.62），難度和原本一樣。
